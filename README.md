# 📄 Bias-Aware Resume Screening

## Overview

This project focuses on building a fair and transparent resume screening system using Natural Language Processing (NLP) and Machine Learning techniques. The objective is to evaluate resumes based on relevant skills and qualifications while promoting unbiased candidate screening and improving recruitment decision-making.

## 🎯 Objectives

- Analyze resumes using NLP techniques
- Extract and preprocess textual information
- Build a machine learning model for candidate screening
- Reduce bias during the resume evaluation process
- Support fair and data-driven hiring decisions

## 🛠️ Tech Stack
